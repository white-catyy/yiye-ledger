# 一页账

面向大学生的轻量记账 App。首页以「今日账页」展示当天收支，明细页通过月历管理历史流水，并支持自定义分类和完整的本地数据迁移。

## 功能

- 查看今日累计、笔数、昨日对比和本月预算进度
- 新增、编辑或删除今日流水
- 流水支持支出和收入切换，金额方向与汇总口径自动同步
- 月历按日查看、编辑和补记今天及过去日期的流水
- 未来日期禁用，切换月份时保留同一天号并自动处理月末
- 内置收入分类包括工资、兼职、奖学金、红包、报销和退款
- 最多创建 20 个自定义分类，合计覆盖收入与支出
- 自定义分类支持名称、跨平台图标和预设颜色，并在设置中统一管理
- 使用中的自定义分类禁止删除，避免历史流水被静默更改
- 首次启动为空账本，金额和预算由用户填写
- 本地自动保存流水、预算和主题
- “我的”页面统一提供预算，以及默认折叠的主题和数据设置
- 支持预设主题色和自定义十六进制颜色
- 导出 V2 `yiye-ledger-backup-YYYY-MM-DD.json`，包含流水类型、分类、预算和主题
- 继续兼容 V1 备份，导入前校验格式、版本、字段和日期，确认后完整替换账本

## 运行

```bash
npm install
npx expo start
```

优先使用 Expo Go 扫码预览。Web 预览：

```bash
npm run web
```

## 验证

```bash
npx tsc --noEmit
npx expo export --platform web --output-dir dist
```

`scripts/verify-app.mjs` 会在本地 Web 服务运行时验证收入与支出、自定义分类数量上限和删除保护、按日明细、预算与主题持久化、V1/V2 备份、损坏文件保护和刷新持久化，并生成六张预览图。
